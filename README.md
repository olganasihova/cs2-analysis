\# CS2: очистка данных и классификация kNN



Учебный проект на данных матчей Counter-Strike 2 с HLTV.



\## Задача



Очистить данные и обучить модель классификации победы первой команды.



\## Что сделано



\- Удалены полные дубликаты и малоинформативные столбцы с пропусками.

\- Проценты и другие числовые показатели преобразованы из текста в числа.

\- Обработаны бесконечные значения и пропуски.

\- Построены графики распределений и связей признаков.

\- Стандартизация и kNN объединены в Pipeline.

\- Число соседей выбрано по пятикратной кросс-валидации.

\- Качество оценено на отдельной тестовой выборке.



\## Результаты



После очистки осталось 1009 наблюдений. Для модели использованы 142 числовых признака.



\- Обучающая выборка: 706 наблюдений.

\- Тестовая выборка: 303 наблюдения.

\- Выбранное число соседей: k = 27.

\- Средняя точность кросс-валидации: 67,99%.

\- Точность на тестовой выборке: 72,61%.



\## Инструменты



Python, pandas, NumPy, matplotlib, seaborn, scikit-learn, Google Colab.



\## Данные



Источник: \[Counter-Strike 2 HLTV Match Data на Kaggle](https://www.kaggle.com/datasets/victorpicinin/counter-strike-2-hltv-match-data).



Данные загружаются в ноутбуке через kagglehub.



\## Как открыть



Загрузить cs2.ipynb в Google Colab и выполнить все ячейки по порядку. Установка библиотек включена в первую ячейку кода.



\## Ограничения



Учебный эксперимент по классификации. Доступность признаков до начала матча и возможные повторения матчей по matchID отдельно не проверялись. Полученная точность не подтверждает качество прогноза будущих матчей.
